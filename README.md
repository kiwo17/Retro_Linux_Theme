# Cyber deck Theme Project

With this Project I want to build a costume Linux Theme for my Cyber deck Project using CSS and Java Script. 
My inspiration is a Cyberpunk aesthetic. 

## Inspiration 

While scrolling on social media on a hot summer day I came upon an video, which woke my devotion for this project. 
I saw a mini Laptop that could fit in a pocket! "How is that possible?!" I thought as I was getting more and more interested. 
I went down a rabbit whole of electronics, programming, Python, Database, Networking, Cybersecurity etc... It is very overwhelming. I felt the need to learn all of those topics ASAP, but knowing that isn't possible I got discouraged and felt unmotivated, because I didn't know where nor how to begin. Now after a lot of thinking I've decided to just go for it. It might not be the ideal path or the perfect roadmap into computer science and electronic, but doing nothing isn't going to get me anywhere. 
Let's see how it ends!

I want to question the code, understand and apply it. Someday I want to be able to build projects from my own thinking and creativity. For now I must make mistakes and learn.
